# Probability

Probability is the language of uncertainty.

Whenever we ask questions like:

- What are the chances of rain tomorrow?
- What is the probability that an email is spam?
- How likely is a customer to buy a product?
- How confident is a machine learning model in its prediction?

we are working with probability.

Probability provides the mathematical framework for reasoning about uncertain events and outcomes.

---

## Why Probability Matters

Machine learning models rarely make decisions with complete certainty.

Instead, they estimate probabilities.

Examples:

- A spam classifier estimates the probability that an email is spam.
- A medical model estimates the probability of a disease.
- A recommendation engine estimates the probability that a user will like a movie.

Understanding probability helps us understand how modern AI systems make decisions.
